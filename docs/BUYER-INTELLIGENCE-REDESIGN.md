# 採購規劃與市場資訊整合

2026-10-02，本機施工分支 `refactor/buyer-journey`；尚未推送或正式部署。

## 最終呈現

三個同等重要的入口：採購規劃、市場與供應更新、市場比較。共用工具類別與目的市場；選擇產品後可帶入目錄照片、型號與產地。沿用玉綠、米白、銅色與襯線字體，縮減深色終端、大表格、重複導覽及首屏輸入表單。

- 採購規劃：先選產品，並用併櫃／整櫃卡片導向成本估算。報價欄位折疊，填入有效資料才顯示計算結果。补貨與成本趨勢保留為簡短的次要切換。
- 市場與供應更新：首屏三則相關主題，附來源、日期與買家下一步核對項目。更多消息與證據折疊。相同事件的來源合併；排除與園藝金屬工具無關的消息。
- 市場比較：預設目的市場加兩個比較市場，可自行移除比較項目。桌面三張卡，手機改成緊湊比較表；搭配進口數量增減圖、簡短解讀及可展開的統計口徑。
- 再訪提示：只在這台瀏覽器記錄公開偏好與已看過的報告識別；有新消息才標示新增。可用清除偏好按鈕重設，不需帳號、資料庫或伺服器寫入。

## 資料邊界

目前進口統計是 **2024 對 2023 年**，不是 2026 即時行情。只有六個市場目前有可用觀測；其他目的市場、未涵蓋類別或缺值清楚顯示無資料。進口單位值是分類統計，不能當作個別產品售價、报价或進口商毛利。

剪枝剪、籬笆剪／高枝剪、鋸、鋤／耙使用既有統計分類參考；手工具與澆灌產品不自動猜測分類。統計分類不能代替逐一 SKU 的海關歸類。

併櫃／整櫃卡片說明比較方式，沒有自動取得即時海運報價。FOB、運費、數量、稅率與交期使用買家填入的條件；網站不公開 Birdland 價格、MOQ 或交期，也不捏造未知費率。成本估算、补貨、金屬歷史趨勢及可調整情境各自保留假設邊界。

消息來自既有 RSS 管線；介面提供固定的核對提示，不宣稱 AI 已判定市場因果或預測。此次沒有增加 AI 呼叫、資料庫、帳號、寄信或正式送單功能。

## 工程責任

| 內容 | 唯一來源 |
|---|---|
| 市場／供應兩頁 | `tools/intelligence_template.html`，由 `config/build.json` 指定模式 |
| 採購規劃頁 | `tools/buying_tools_template.html` |
| 三頁公開資訊與呈現 | `buyer-intelligence.js`、`buyer-intelligence.css` |
| 共用公開偏好 | `buyer-focus.js`：`bl_buyer_focus`、`bl_buyer_seen` |
| 精簡消息檔 | `tools/build/intelligence.js` → `buyer-intelligence.json` |
| 統計年份與擷取 | `tools/fetch_trade.py` → `trade.json.periods` |
| 成本／补貨計算 | `buyer-tool-models.js`、`buyer-tools.js` |
| 官方型號與照片 | `data/catalogue-manifest.json` → `catalog.json` |

`bl-cat` 的公開型號／尺寸清單保留，數量與自由文字不持久保存；價格與報價輸入重新整理即清空。跨分頁偏好同步不回寫事件，避免循環。資料檔獨立載入，單一來源失敗不阻止其他功能。

既有成本深連結導向對應新任務；工程選項連結保留。市場 `?cell=family|iso` 帶入共用條件；舊 Desk／Edition 視圖合併為同一個比較畫面。舊新聞主題、追蹤、日曆與成本錨點保留目的地。每日 CI 重建兩頁及精簡消息檔，沿用既有資料來源。

## 全站視覺精簡（2026-10-02）

Products 預設 12 款，每次增加 12 款；搜尋與分類仍涵蓋全部 69 款。詳情與詢價清單統一使用可關閉、回復焦點的 dialog，桌面不再常駐重複側欄。製造範圍說明可展開，首頁原圖保留並提前提供產品入口。

補貨預設三項：庫存、每週銷量、包含安全緩衝的總補貨週數。展開進階設定時改用生產＋運輸＋緩衝三項，總時間欄位停用，避免混算。`buyer-tool-models.stock` 的 `mode: total` 支援新模式，舊呼叫仍使用拆分模式。未輸入交期不計算。手機有有效結果時出現摘要與查看明細按鈕；切換任務或清空無效資料時移除提示。

製造頁先看金屬製造、品質控制、OEM 合作，重用原始製程照片與圖解；所有技術章節保留原錨點並可展開。Guide、配置頁移除第二層品牌導覽；手機配置型號選單折疊。Contact 顯示官方對應窗口信箱、複製地址，`partner.html#enquiry` 直接開既有清單。沒有寄信、資料庫、公開商業條件或部署。

驗證包含建置、生成檔一致性、12 頁桌面／手機與十語言、型錄分批與選單焦點、簡易／拆分補貨一致性、手機結果、舊錨點、清單與信箱複製。另對 1440／375px 全頁及主要互動狀態截圖；截圖在 repo 外的 `../shots/review-all`。

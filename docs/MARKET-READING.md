# Market Compare 閱讀優化

2026-10-03：使用者確認桌面／手機模擬圖後授權實作。僅調整 Market Compare，保留深色分析工作台、紫色識別、原 App 圖示與奶油色「本期解讀」。Supply Updates 與 Product Studio 沿用前次決定。

## 主流程

預設開啟 Compare：選工具類別與自己的市場，查看三項摘要、最多三市場的四指標比較表、一句客觀解讀，再帶入 Purchase Planning。比較市場可更換或清除；僅在相同類別與數量基準下提供可用比較市場。沒有資料的自有市場仍可選取，顯示缺資料提示與破折號，不填入推測值。

其他類別與完整市場、比較清單、來源定義、上次造訪變化集中到四個展開區。原市場搜尋、收藏、清單增刪／詢問、詳細統計與級距、安裝、版本、大字模式仍可操作。原 Desk / This edition 的 #desk / #brief、?cell=HS|market、?sheet=1 與 ?edition= 舊網址保留。本期解讀不刪除原類別報告與市場章節。

新閱讀層使用原頁面已載入並正規化的 trade.json，不另取一次相同資料、不增加 AI 請求、資料庫或會員。原模板透過受限介面同步選取狀態與操作，避免維護兩套統計資料。比較清單複製包含實際資料期間；主要採購規劃連結傳遞公開市場與可對應的工具類別，不傳遞價格或訂單。

## 資料解讀

統計期間取 trade.json.periods，目前為年度 2024 對 2023。2026-Q4 只標示刊物版次；generated 僅代表建置時間。若缺 periods，不推測日期。統計平均單位值不是產品報價；進口占比不能證明某供應商搶走訂單。原先因果式解讀與「中國價格攻勢」分類改為客觀的數量、單位值、產地占比變化。原數值與來源不改動。

未載入資料時可閱讀缺資料狀態，保留既有收藏與造訪快照，不用空資料覆蓋已儲存偏好。bl_mm_mine / bl_mm_sheet / bl_mm_snap 等既有儲存名稱保留；新 bl_mm_compare 只存最多兩個公開市場代碼。

## 維護

來源是 tools/restored-market_template.html 與 market-reading.js / market-reading.css；my-market.html 由 npm run build 產生。新增介面文字集中於 config/languages.json，支援原十種語言。原市場文章與類別翻譯仍使用既有 i18n。

驗證包含全站既有檢查、桌面與手機視覺、十種語言、比較切換／清除持續性、空市場與空資料、舊深層網址、原市場搜尋及收藏清單、大字模式、複製與採購規劃銜接。尚未推送或正式部署。

# Buying tools 操作流程重整（2026-10-02）

本次將採購入口與實際計算操作合併為 `buying-tools.html`，保留原本翡翠綠、米白、銅色、襯線標題、即時結果，以及「輸入 → 結果 → 複製」的有用設計。

## 改版依據

實際檢視原本的入口和 Cost workspace：入口有兩組標題與多層參考資料；點入後又出現上下文側欄、七個功能入口、安裝提示、預填費率、零售結果和產地比較。它們同時要求買家理解太多概念，也讓模擬數字看起來像已確認的報價。單純把資訊折疊仍然沒有解決「今天要完成什麼」的問題。

## 主入口只保留三個任務

| 買家問題 | 先輸入 | 主要結果 | 次要功能 |
| --- | --- | --- | --- |
| 這批貨每件成本是多少？ | FOB 整批貨值、數量、運費 | 未含進口稅的每件成本、整批現金需求 | 展開關稅／稅／保險／雜費；選填毛利率 |
| 何時需要再次下單？ | 現有庫存、每週銷量、生產／運輸／安全週數 | 最晚下單日、庫存週數、補貨門檻 | 複製規劃摘要 |
| 市場成本有什麼變化？ | 選金屬；情境試算才輸入成本占比 | 實際月度觀測、加權情境結果 | 航線資料來源、月份明細、市場參考 |

一次只呈現一個任務；手機和桌面都有用途說明。進入工具不再開啟另一套有側欄和狀態欄的 dashboard。未輸入必要數字時不顯示虛構範例成果；未填附加費用按零計，結果明列採用的稅率和計價基礎。

## 明確移出主流程的功能

- 航班式模擬船期、推算可用艙位與即時運費：缺少可驗證的實際訂艙資料，改用買家自己的運輸時間與運費。
- 自動產地關稅比較、國家預填稅率：各貨品分類、附加稅和計價條件不同，改由買家輸入確認過的假設。
- 重複零售毛利面板：合併成成本工具中的選填定價試算。
- 安裝提示、商業區域側欄、重複資訊入口：不再介入三個採購任務。
- My Market 和新聞長文：留在「成本趨勢 → 市場參考」的單層折疊項目，沒有刪除原本網址。

## 工程邊界

- `tools/buying_tools_template.html`：唯一公開工具模板；`tools/build/site.js` 渲染英文靜態內容和共用架構。
- `buyer-tool-models.js`：純成本／補貨計算，不含資料抓取、報價、法定費率、DOM 或儲存。
- `buyer-tools.js`：欄位驗證、任務切換、結果呈現、複製及手動複製備援。
- `buyer-tools.css`：任務入口、輸入、結果和手機版。
- `buyer-planning.js`／`.css`：已驗證的原物料趨勢與買家加權情境；繼續使用既有月資料來源。
- `config/languages.json`：十種語言的用途說明、標籤與驗證文字。
- `cost-entry.js`：舊成本連結相容路由。`p-landed2`／`p-margin`／`p-cduty` 到進口成本；`p-reorder`／`p-sail` 到補貨；`p-mkt` 到成本趨勢。這是遷移至精簡任務，不承諾保留原本模擬功能。
- `pd-*`／`mat-*` 和 `engineering-options` 舊工程深連結仍保留原工程模板；它是相容邊界，沒有將整套舊計算器當成另一個主入口。後續如拆出工程模板，可再移除剩餘舊版依賴。

沒有新增資料庫、帳號、外部寫入或營運工作流。買家金額、數量、時間只保存在當頁記憶體，重新整理清除，不加入 localStorage、不發送至伺服器。公開頁面不放 Birdland 的價格、MOQ 或交期；輸入都是買家自己的假設。複製內容為純文字。

## 計算定義及限制

成本：CIF = FOB + 運費 + 保險；關稅 = 選定 FOB 或 CIF 基礎 × 輸入稅率；未含進口稅成本 = CIF + 關稅 + 雜費；進口稅的簡化假設為 (CIF + 關稅) × 輸入稅率；現金需求再加進口稅。此工具不模擬特定國家完整課稅規則，其他應付費用由買家納入雜費。

毛利價格 = 選定每件成本 ÷ (1 − 毛利率)。使用者可將進口稅納入定價成本，避免把不可抵扣稅一律排除；結果不是最終帳務成本或公司報價。會计處理依買家的具體稅務情況而定。參考 [IAS 2 第 11 段](https://www.ifrs.org/content/dam/ifrs/publications/html-standards/english/2026/issued/ias2.html)，採購成本對可收回稅與其他稅採不同處理。

補貨：庫存週數 = 庫存 ÷ 週銷量；安全需求週數 = 生產 + 運輸 + 安全緩衝；等待週數 = 庫存週數 − 安全需求週數，低於或等於零即「現在下單」。其他情況將等待天數向下取整，避免將最晚日期延後。假設穩定銷量、沒有在途訂單，沒有自行推算建議下單數量。

原物料仍只有已取得來源的鋁、鎳月資料，沒有杜撰鋼材、加工費或航運即時指數。使用者必須使用實際航線和供應商報價作決策。現有排程接線要在正式上線後才生效，本次未推送或部署。
